## Installed package and real source evidence

The prepared wheel's 225 package files matched the frozen source. Independent
installation also checked metadata, recorded files, exported interfaces, command
help and typed examples, without an editable project or platform SDK import.
Optional dependencies came from existing accepted environments; this is not
admission of every deployment or optional model runtime.

Actual installed native parsing retained the complete original Chinese PDF:
47 pages and 24,400 native characters. Native corpus append/query and the
retained evidence reader preserved the original document, passage offsets and
acknowledged embedding identities. Fresh reader calls reused those identities
without making another embedding request. Retained source age remains unknown;
the reader does not claim to have freshly verified the current research intent.

Artifact-pinned CPU learned reranking executed over the complete native hybrid
candidate union. It improved the organizational passage's rank for one English
query but worsened the corresponding full Chinese query. These are individual
observations, not calibrated accuracy. The reranker remains an explicit recipe
choice, not a multilingual default. Literal language filters also retain their
documented semantics: a model label `Chinese` is not automatically rewritten to
the extractor code `zh`.

The bounded independently installed command/service recovery check passed all
26 cases in 316.49 seconds, without failures or skips, under Python 3.11.16 at
`/tmp/chimera-c0-20261006/.venv/bin/python`. Tests and examples came unchanged
from the verified source archive into scratch with no `src` directory. The
explicit installed-wheel import path was inherited by fresh child processes;
dependencies were reused from the existing acceptance environment. Pytest
discovered the parent workspace's verbosity/marker/warning configuration; that
configuration does not supply a project import path, and no workspace test was
selected. This was not a fresh admission of every optional runtime.

The cases exercise controlled process cuts, original acknowledgements,
authenticated loopback recovery and refusal paths. Such fixtures do not
establish actual remote service readiness or model quality.
